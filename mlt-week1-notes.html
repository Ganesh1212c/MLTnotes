PCAShrink the data. Keep the story.

This week is about one clever trick: describing a big, many-featured data set with just a few numbers per point, and losing as little as possible. By the end you will know what a principal component is, why it is an eigenvector, and how many to keep.

Lesson 1

What is machine learning?

The idea: machine learning lets a computer find patterns in data and use them to predict or decide, without a person writing every rule by hand.

Why

To automate jobs that normally need human judgement, to handle huge amounts of data, and to make predictions or decisions more accurately than older approaches.

Where

Computer vision, natural language processing, finance, healthcare, and many more fields.

What

It is driven by data, not by hand-written steps. It does not memorise examples, it tries to generalise the pattern. There is no magic, only mathematics and algorithms.

The three broad paradigms

A label is the correct answer attached to an example (for instance, the price of a house). Whether the data has labels decides the paradigm.

ParadigmWhat it learns fromGoalExamples in the notes
Supervised Labelled data: inputs and their outputs Predict the output for new, unseen inputs Linear regression (continuous output), logistic regression (binary classification), decision trees, support vector machines, neural networks
Unsupervised Unlabelled data: inputs only Uncover patterns or relationships with no guidance Clustering (K-means, hierarchical, density-based), dimensionality reduction (PCA), anomaly detection
Sequential Sequences, where each step depends on the earlier steps Predict from the order of the data Time-series forecasting, speech recognition, natural language processing
  1. Does each example come with the right answer? Yes means supervised.
  2. No answers, only inputs? Unsupervised.
  3. Does the order of the data matter, like days in a row? Sequential.

Where this week lives: PCA is unsupervised. It looks only at the inputs, finds structure, and never needs a label.

Exam trap

PCA does not use labels and it is not a classifier. It is a tool for describing the data more compactly, often before another algorithm takes over.

Lesson 2

Your maths toolkit

The idea: every formula this week is built from a handful of small ideas. Skim the ones you know and open the ones you do not. Each has a tiny example with real numbers.

8 quick refreshers

BasicsA vector, and what ℝd means

A vector is just a list of numbers. If every student has a height and a weight, one student is a list of two numbers, such as x = (170, 65). We say this vector lives in ℝ2 (read "R two"). A data point with d features lives in ℝd.

In this week: xi is the i-th data point, n is how many points there are, and d is how many features each point has.

About "weights": a model often stores a list of weights, meaning "how much each feature counts". That is also a vector. Here, w plays a different role: it is a direction.

BasicsThe dot product xTw

Multiply the matching entries of two vectors and add everything up. The answer is one single number.

xTw = x1w1 + x2w2 + … + xdwd

Example: for x = (2, 3) and w = (4, 1), the dot product is 2·4 + 3·1 = 11.

The small T means "transpose": it turns a column into a row so the multiplication lines up. You can simply read xTw as "x dot w". When w has length 1, this number tells you how far x reaches along the direction of w.

BasicsLength ‖w‖ and unit vectors

The length (or norm) of a vector is the square root of the sum of its squared entries.

‖w‖ = √( w12 + w22 + … + wd2 )

Example: for (3, 4) the length is √(9 + 16) = 5. A unit vector has length 1. To make one, divide by the length: (3, 4) ÷ 5 = (0.6, 0.8), and indeed 0.36 + 0.64 = 1.

For a unit vector, wTw = ‖w‖2 = 1. This tiny fact makes the main formulas simpler.

BasicsMean and centring the data

The mean μ is the average data point. Centring means subtracting μ from every point, so the cloud of data sits around the origin.

μ = 1n nΣi=1 xi,    xi xi − μ

Example: take the points (2, 4), (4, 2), (6, 8), (8, 6). The mean is (5, 5). After centring they become (−3, −1), (−1, −3), (1, 3), (3, 1). We will use these four points all week.

BasicsThe sum sign Σ

Σ means "add up all the terms". The little text under and over it says where to start and stop.

nΣi=1 ai = a1 + a2 + … + an

Example: with ai = i2 and n = 3, the sum is 1 + 4 + 9 = 14. The factor 1n in front just turns a sum into an average.

BasicsMatrices, and the table xxT

A matrix is a table of numbers. "d × n" means d rows and n columns. In the notes, the whole data set is a d × n table with one column per data point.

Multiplying a column vector by its own row gives a square table (d × d). Example: for x = (1, 2),

xxT = 1224

The covariance matrix C that appears later is simply the average of these tables over all the data points.

BasicsEigenvectors and eigenvalues

A matrix C acts on a vector by turning and stretching it. An eigenvector is a special direction that C does not turn. It only stretches it, by a factor λ called the eigenvalue.

Cw = λw

Example: let C = 5335 and w = (1, 1). Then Cw = (5+3, 3+5) = (8, 8) = 8·(1, 1). So (1, 1) is an eigenvector and λ = 8.

BasicsVariance: how spread out is it?

Variance measures spread: the average squared distance from the mean. Tightly packed numbers have a small variance, scattered numbers a large one.

Example: the numbers −2, 0, 2 have mean 0 and variance (4 + 0 + 4) ÷ 3 ≈ 2.67. The numbers −1, 0, 1 have variance (1 + 0 + 1) ÷ 3 ≈ 0.67, so they are more tightly packed.

For centred data and a unit direction w, the spread along w is 1n nΣi=1 (xiTw)2. That one expression is the star of Lesson 4.

Lesson 3

Representation learning: compress and rebuild

The idea: find a shorter way to describe each data point, so that we can rebuild the point later with as little damage as possible.

Representation learning is about finding meaningful, compact descriptions of complicated data. That helps with dimensionality reduction, clustering and classification.

We have a data set {x1, x2, …, xn} where every xi ∈ ℝd. The aim is to find a representation with the smallest reconstruction error. We start small: look for the best single direction w, with the rule ‖w‖ = 1.

Step 1: the shadow on the line

Picture a line through the origin pointing along w. Shine a torch straight onto it, and every data point casts a shadow on the line. The position of the shadow is the single number xiTw. That is one number instead of d numbers. To rebuild the point from it, walk that far along w.

projection = xTwwTw w  ⟶  since ‖w‖ = 1,   projection = (xTw) w

Step 2: what gets lost

The rebuilt point is not exactly the original. The leftover is called the residue, written x′. The reconstruction error is the average squared length of the residues.

f(w) = 1n nΣi=1 ‖ xi − (xiTw) w ‖2
Worked mini example

Take x = (5, 0) and the unit direction w = (0.6, 0.8).

  1. xTw = 5·0.6 + 0·0.8 = 3. This is the shadow position.
  2. Projection = 3·(0.6, 0.8) = (1.8, 2.4).
  3. Residue = (5, 0) − (1.8, 2.4) = (3.2, −2.4).
  4. Squared error = 3.2² + 2.4² = 10.24 + 5.76 = 16.
Remember

One number per point (xTw) instead of d numbers. The price we pay is the residue.

Exam trap

The short formula (xTw)w only works because ‖w‖ = 1. If a question gives a w that is not unit length, divide by wTw first.

4

Lesson 4

The big trick: least error means most spread

The idea: the best direction is the one where the shadows are spread out the most. Shadows that pile on top of each other throw away the difference between points.

To pick the best w we need to minimise the reconstruction error. Four small steps turn that into something we can solve.

  1. Use Pythagoras

    For every point, x, its projection and its residue form a right-angled triangle, with x as the longest side. So (for a unit w):

    ‖x‖2 = (xTw)2 + ‖residue‖2

    Move things around: ‖residue‖2 = ‖x‖2 − (xTw)2.

  2. Average over all the points

    f(w) = 1n nΣi=1 ‖xi‖2  −  1n nΣi=1 (xiTw)2

    The first part never changes, because it only depends on the data and not on w. So making the error small is the same as making the second part large. The notes write this as minimising −1nΣ(xiTw)2, which is the same thing:

    max‖w‖=1 1n nΣi=1 (xiTw)2

    For centred data this is exactly the variance of the shadows, the spread.

  3. Rewrite it with the covariance matrix

    Since (xiTw)2 = wTxixiTw, we can pull w out of the sum:

    1n nΣi=1 (xiTw)2 = wT (1n nΣi=1 xixiT) w = wTCw

    The matrix C is the covariance matrix of the centred data. It is d × d, so C ∈ ℝd×d. (Some textbooks divide by n − 1. This course divides by n.)

  4. Read off the answer

    We now need the unit vector w that makes wTCw as big as possible. The answer is the eigenvector of C with the largest eigenvalue λ. It is called the first principal component of the data set.

Our four points, in numbers. After centring, C = 5335. Its eigenvalues are 8 and 2, and the eigenvector for 8 is (1, 1)/√2. So the best direction runs diagonally, right through the long axis of the cloud. The playground below lets you check that with your own eyes.

Exam trap

The goal is to maximise wTCw, not minimise it. And it only means "variance" when the data has been centred first.

Lesson 5

The potential algorithm: peel off one direction at a time

The idea: take the best direction, remove everything it explains, find the best direction for what is left, and repeat.

One direction is rarely enough. The notes outline a simple recipe (called the "potential algorithm") for a data set {x1, …, xn} with every xi ∈ ℝd:

  1. Centre the data

    μ = 1n nΣi=1 xi,    xi xi − μ   for every i

  2. Find the best direction

    Find the unit vector w ∈ ℝd with the least reconstruction error (Lesson 4).

  3. Remove what it explains

    xi xi − (xiTw) w   for every i

    Each point is replaced by its residue.

  4. Repeat steps 2 and 3

    Keep going until the residues become zero. The directions you collect are w1, w2, w3, …, wd.

Watching it work on our four points

After round 1 the residues are (−1, 1), (1, −1), (−1, 1) and (1, −1). They all lie along one line, the direction w2. So round 2 finds w2, removes it, and every residue is now zero. We stop. Since d = 2, we needed two directions in total.

RoundDirection foundSpread it capturesError left after it
1w1 = (1, 1)/√282
2w2 = (1, −1)/√220

The notes end this section with two questions: is this the most effective approach, and how many w do we really need? Lesson 6 answers both.

Remember

Each new direction is chosen from what is left over, so it comes out at a right angle to the ones before it.

Exam trap

Step 1 matters. If you skip the centring, the "best direction" chases the position of the cloud instead of its spread.

Lesson 6

PCA: which directions, and how many?

The idea: Principal Component Analysis keeps only the top k directions, the ones that explain the most variance, and throws the rest away.

6.1 Rebuilding a point exactly

If we keep all d directions, every residue is zero, so each point can be rebuilt perfectly as a linear combination of the directions:

xi = (xiTw1)w1 + (xiTw2)w2 + … + (xiTwd)wd

So we store the numbers xiTwj (the coefficients) and the vectors w1, …, wd.

6.2 Does it actually save space?

What we storeHow many numbersIf d = 100, n = 1000, k = 5
The original d × n datadn100,000
All d directionsd(d + n)110,000 (bigger!)
Only k directionsk(d + n)5,500

With all d directions we store d coefficients for each of the n points (dn numbers) plus d vectors of d numbers each (d2). That is more than we started with, which looks pointless. The payoff comes when the data really lives in a smaller space. If k directions are enough, with k ≪ d (much smaller than d), the storage drops from d × n to k(d + n).

6.3 Eigenvalues are variances

Let C be the covariance matrix of the centred data. Its eigenvalues {λ1, …, λd} are never negative (because C is positive semi-definite). We list them from biggest to smallest, with unit eigenvectors w1, …, wd. Start from the eigen equation and multiply by wT on the left:

Cw = λw  ⟹  wTCw = λwTw = λ  ⟹  λ = 1n nΣi=1 (xiTw)2

That is exactly the spread from Lesson 4. Because the data is centred, λ is the variance captured by its eigenvector w. A bigger eigenvalue means a more important direction. And as the notes say, the higher the variance captured, the lower the error.

6.4 How many to keep: the 95% rule

A commonly used rule of thumb is to capture at least 95% of the total variance. Keep the smallest k for which

kΣj=1 λjdΣi=1 λi  ≥  0.95

6.5 The PCA algorithm

For a centred data set {x1, …, xn}, xi ∈ ℝd, with covariance matrix C:

  1. Find the eigenvalues and eigenvectors of C

    Sort the eigenvalues in descending order, λ1 ≥ λ2 ≥ … ≥ λd, and pair each with its unit-length eigenvector w1, …, wd.

  2. Choose k

    Pick the number of top eigenvalues and eigenvectors you need to cover the variance you want (for example 95%).

  3. Project the data

    Project every point onto the k eigenvectors. The representation is the linear combination of those projections: xi ≈ (xiTw1)w1 + … + (xiTwk)wk.

6.6 The one-line summary

PCA is a dimensionality-reduction technique that finds feature combinations that are de-correlated. The notes describe these as independent of each other, which means each new feature carries information the others do not. It is valuable for visualising high-dimensional data and for preparing data before other machine-learning tasks.

Remember

Eigenvalues are variances. Sort them from biggest to smallest, add them up until you reach about 95% of the total, and that count is k.

Exam trap

Divide by the sum of all the eigenvalues, not by the biggest one. And 95% is a common rule of thumb, so if a question names a different target, use that one.

Worked numeric problems

These are the kinds of calculations that show up in assignments and previous year papers. Try each one on paper first, then open the solution to compare.

1

Project a point and measure the error

Let x = (2, 6) and w = (0.8, 0.6). (a) Is w a unit vector? (b) Find xTw. (c) Find the projection. (d) Find the residue and its squared length. (e) Confirm with Pythagoras.

Show the solution
  1. (a) ‖w‖2 = 0.82 + 0.62 = 0.64 + 0.36 = 1. Yes, it is a unit vector.
  2. (b) xTw = 2·0.8 + 6·0.6 = 1.6 + 3.6 = 5.2.
  3. (c) Projection = 5.2·(0.8, 0.6) = (4.16, 3.12).
  4. (d) Residue = (2, 6) − (4.16, 3.12) = (−2.16, 2.88). Its squared length is 4.6656 + 8.2944 = 12.96.
  5. (e) ‖x‖2 = 4 + 36 = 40, and (xTw)2 = 5.22 = 27.04. Then 40 − 27.04 = 12.96, which matches. ✓

Shortcut: you never need the residue itself to get the error. Use ‖x‖2 − (xTw)2.

2

Centre the data and find the covariance matrix

A data set has four points: (2, 4), (4, 2), (6, 8), (8, 6). (a) Find the mean. (b) Centre the data. (c) Compute C = 14 Σ xixiT. (d) Find the eigenvalues and unit eigenvectors of C.

Show the solution
  1. (a) Mean = ((2+4+6+8)/4, (4+2+8+6)/4) = (5, 5).
  2. (b) Subtract (5, 5) from each point: (−3, −1), (−1, −3), (1, 3), (3, 1).
  3. (c) Each xxT is a 2 × 2 table. For (−3, −1) it is 9331, for (−1, −3) it is 1339, and (1, 3) and (3, 1) give the same two tables again. Adding all four gives 20121220. Divide by 4: C = 5335.
  4. (d) Solve (5 − λ)2 − 32 = 0. So 5 − λ = ±3, giving λ = 8 and λ = 2. For 8 the eigenvector is (1, 1)/√2, and for 2 it is (1, −1)/√2. Check the first: C(1, 1) = (8, 8) = 8·(1, 1). ✓

Shortcut: for a symmetric matrix of the form [[a, b], [b, a]], the eigenvalues are a + b and a − b, with eigenvectors (1, 1) and (1, −1).

3

Variance captured and error with one direction

Using Problem 2, suppose we keep only the first principal component w1 = (1, 1)/√2. (a) What variance does it capture, and what fraction of the total is that? (b) Rebuild the first centred point (−3, −1) from w1 alone. (c) What is the average reconstruction error? (d) Does it reach the 95% rule?

Show the solution
  1. (a) The variance captured is the eigenvalue λ1 = 8. The total is 8 + 2 = 10, so the fraction is 8/10 = 80%.
  2. (b) Coefficient: xTw1 = (−3 − 1)/√2 = −2√2 ≈ −2.83. Rebuilt point: −2√2 · (1, 1)/√2 = (−2, −2). The residue is (−3, −1) − (−2, −2) = (−1, 1), with squared length 2.
  3. (c) Every point has residue squared length 2 (the other three also work out to 2), so the average error is 2. This equals the eigenvalue we dropped, λ2 = 2, and 8 + 2 = 10, the total.
  4. (d) No. 80% is below 95%, so the 95% rule says to keep both directions (k = 2).
4

How many components should we keep?

A data set has eigenvalues 50, 25, 12, 8, 3, 2. What is the smallest k that captures (a) at least 95% of the variance, (b) at least 90%, (c) at least 80%?

Show the solution

The total is 50 + 25 + 12 + 8 + 3 + 2 = 100. Add the eigenvalues in order and watch the running total:

k123456
Captured50%75%87%95%98%100%
  1. (a) k = 4. The target is "at least" 95%, and exactly 95% counts.
  2. (b) k = 4. With three directions we only have 87%, which is below 90%.
  3. (c) k = 3. Two directions give 75% (too low), three give 87%.
5

Count the numbers we store

A data set has d = 100 features and n = 1000 points. How many numbers are needed to store (a) the original data, (b) a PCA representation with k = 5, (c) a representation that uses all d directions? (d) How many times smaller is (b) than (a)?

Show the solution
  1. (a) d × n = 100 × 1000 = 100,000.
  2. (b) k(d + n) = 5 × 1100 = 5,500.
  3. (c) d(d + n) = 100 × 1100 = 110,000, which is more than the original.
  4. (d) 100,000 ÷ 5,500 ≈ 18.2 times smaller.

Read the question carefully: the formula is k times (d plus n), not k times d times n.

Cheat sheet

Setup

Data {x1, …, xn}, xi ∈ ℝd. Centre it first: xi xi − μ.

Projection and residue

For ‖w‖ = 1: projection = (xTw)w. Residue x′ = x − (xTw)w. And ‖x′‖2 = ‖x‖2 − (xTw)2.

The goal

Minimum error is the same as maximum spread: maximise 1nΣ(xiTw)2 = wTCw over unit w.

Covariance and the answer

C = 1nΣxixiT is d × d. The first principal component w1 is the eigenvector of the largest eigenvalue.

Eigenvalues are variances

λj = 1nΣ(xiTwj)2 is the variance along wj. They are never negative and are sorted from largest to smallest.

How many to keep

Smallest k with (λ1 + … + λk) ÷ (λ1 + … + λd) ≥ 0.95.

Storage

Original dn. All d directions: d(d + n). Only k: k(d + n).

PCA in three steps

1. Eigen-decompose C and sort. 2. Choose k. 3. Project the data onto the top k eigenvectors.

Paradigms

Supervised: labels, predict outputs. Unsupervised: no labels (PCA, clustering, anomaly detection). Sequential: order matters (time series, speech, text).

Five traps

Centre first. Keep w at length 1. Maximise wTCw, do not minimise it. Sort eigenvalues in descending order. PCA never uses labels.
